Content OS

Turn what you do into posts worth reading.

Content OS turns your notes, drafts and photos into LinkedIn and X posts that still sound like you, and helps you spot what’s worth posting in the first place. It’s for engineers, founders and builders with more to share than time to write it up.

I’m building it and use it for my own posts.

One post, start to finish

What I typed in

So I kind of build this stuff prompt MCP style using Daydream but then since agent drifted to rebuild everything in [ffmpeg] always (probably easier as bulk of my "platform" is code and scripts) I decided for benchmarking to recreate in without daydream and here is the result

As typed into Content OS on 16 November, with one misspelled tool name corrected in brackets.

What I posted

I started this edit in Daydream, with an agent controlling the editor through MCP.

But it kept gravitating towards code and scripts instead of using the editor, rebuilding things in ffmpeg. Probably easier for it, as the bulk of my "platform" is code anyway. Eventually I decided to see if I could reproduce the same edit without Daydream at all, in my own code-based editing/rendering setup.

What I hadn't really appreciated is how much of the editing work ffmpeg can handle when an agent is generating the commands.

Left is v2, made with Daydream; right is v3, made without it.

See it on LinkedIn

Content OS wrote the drafts, ten versions, while I steered it in five short chat messages. Every sentence traces back to my note or my replies, and when I asked for more about ffmpeg, it added nothing my notes couldn’t back up. Mostly it found the order and cut the rambling.

How a post gets made

  1. Start with what happened

    Paste a thought, a page of notes, a rough draft, a link or a photo. Or point it at your notes, voice memos or something you read, and pick from the ideas it finds.

  2. Find the point

    If the point is clear, you get a draft right away. If it isn’t, it offers a few angles to choose from.

  3. Edit with an editor

    Changes arrive as suggestions you accept or reject. A check flags claims your notes don’t support and lines that don’t sound like you, and before you approve, it lists the claims in the post for you to confirm.

  4. Post it yourself

    Preview it as LinkedIn or X shows it, copy it and post it. It keeps a record of what went out.
